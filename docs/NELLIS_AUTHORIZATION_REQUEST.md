# Nellis data-access inquiry

Template for the official Nellis Auction support form:

> Subject: Read-only personal auction reporting
>
> I am building a small, read-only personal tool that identifies Phoenix-area
> listings matching saved criteria and emails me a daily summary. It never
> places bids, accesses another user's data, bypasses controls, or redistributes
> listing content.
>
> Do you offer an API, export, affiliate feed, or saved-search notification for
> retrieving active listing fields such as inventory number, title, URL, current
> bid, estimated retail, buyer premium, condition, pickup location, image URL,
> bid count, and closing time?

Keep any reply with the private deployment records. Do not add credentials,
private endpoints, or contact details to this public repository.
